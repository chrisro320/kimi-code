Set the status of the current goal — how you resume, complete, or block an autonomous goal.

- `active` — resume a paused or blocked goal when the user explicitly asks you to work on that goal.
- `complete` — the objective is satisfied and any stated validation has passed; the goal ends and a completion summary is recorded. Verify current state against the actual objective and every explicit requirement first, and treat weak or indirect evidence as not complete. Never use `complete` merely because a budget is nearly exhausted or you want to stop.
- `blocked` — a genuine impasse prevents useful progress: an external condition, required user input, missing credentials or permissions, a persistent technical failure, or an impossible, unsafe, or contradictory objective. For non-terminal blockers, the same condition must repeat for at least 3 consecutive goal turns (counting the original/user-triggered turn and automatic continuations) before you call `blocked`; a resumed goal starts a fresh blocked audit. If the objective itself is impossible, unsafe, or contradictory, call `blocked` in the same turn instead of running more goal turns. Never use `blocked` because work is large, hard, slow, uncertain, incomplete, still needs validation, would benefit from clarification, or needs more goal turns. Once the 3-turn threshold is met and you cannot make meaningful progress without user input or an external-state change, call `blocked` rather than leaving the goal active.

Most active goal turns should not call this tool: after one useful slice of work with material work remaining, end the turn normally without calling UpdateGoal; the runtime will prompt you to continue next turn. Call `complete` only when all required work is done, stated validation has passed, and no useful next action exists — not after only a plan, summary, first pass, or partial result. If you call `blocked`, explain the blocker in your next message. Setting the status is the machine-readable signal; the completion summary or blocker explanation is yours to write.
