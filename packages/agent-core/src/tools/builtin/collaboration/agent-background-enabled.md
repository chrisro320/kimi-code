When `run_in_background=true`, the subagent runs detached from this turn; completion arrives in a later turn as a synthetic user-role message with its result — no polling, sleeping, or progress checks needed. Continue with other work or respond to the user. Never fabricate or predict the result.

Default to a foreground subagent (omit `run_in_background`) when your next step needs its result. Use `run_in_background=true` only when you have other work meanwhile and don't need the result to proceed. Never launch in the background and then immediately wait on it (`TaskOutput block=true`, sleeping, or otherwise) — that blocks the turn for no benefit; run it in the foreground instead.
